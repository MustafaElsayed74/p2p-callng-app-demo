# ConnectPulse - P2P WebRTC App-to-App Calling Web App

تطبيق ويب لإجراء مكالمات صوت وفيديو ومشاركة الشاشة وشات فوري مباشرة بين الأجهزة (Peer-to-Peer) باستخدام WebRTC و Node.js و Socket.io.

---

## 🌟 المميزات (Features)
- 🚀 **اتصال مباشر P2P**: تدفق فوري للصوت والصورة بدون تأخير وباستخدام WebRTC.
- 🔑 **Unique Peer ID**: كود اتصال فريد لكل مستخدم ورابط دعوة للمشاركة السريعة.
- 🎵 **نغمات رنين برمجية**: توليد نغمات الاتصال والاستقبال عبر Web Audio API دون الحاجة لملفات خارجية.
- 🖥️ **مشاركة الشاشة (Screen Sharing)**: إمكانية مشاركة الشاشة أثناء المكالمة مع إمكانية التبديل والرجوع للكاميرا.
- 💬 **شات فوري (In-Call Chat)**: تبادل الرسائل النصية والروابط في الوقت الفعلي أثناء المكالمة.
- 🌊 **Audio Visualizer**: رسم بياني تفاعلي لموجات الصوت يوضح من يتحدث حاليًا.
- 🎨 **تصميم عصري Dark Glassmorphic**: واجهة متجاوبة بالكامل على الهواتف والأجهزة المكتبية.

---

## 🛠️ التثبيت والتشغيل (Installation & Setup)

1. تثبيت الاعتماديات:
```bash
npm install
```

2. تشغيل السيرفر:
```bash
node server.js
```

3. فتح المتصفح على:
```
http://localhost:3500
```
