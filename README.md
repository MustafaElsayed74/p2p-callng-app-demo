# ⚡ ConnectPulse PRO

> **منصة اتصال فوري ومباشر (Peer-to-Peer) عبر الصوت، الفيديو، ومشاركة الشاشة بجودة فائقة بدون خادم وسيط لنقل الميديا.**

---

## 🌟 نظرة عامة (Overview)

**ConnectPulse PRO** هو تطبيق ويب متكامل مبني بتقنية **WebRTC** الحديثة و **Node.js** و **Socket.io**. يتيح للمستخدمين إجراء محادثات مرئية وصوتية ومشاركة الشاشة وتبادل الرسائل الفورية مباشرة بين الأجهزة (P2P) بأعلى سرعة وأقل زمن استجابة (Ultra-low Latency)، مع واجهة تفاعلية زجاجية (Dark Glassmorphism) متجاوبة بالكامل مع شاشات الكمبيوتر والهواتف الذكية.

---

## 📐 المعمارية وطريقة العمل (Architecture & Data Flow)

```
                           [ خادم الإشارات Signaling Server ]
                                  (Node.js + Socket.io)
                                    /              \
                          Signaling /                \ Signaling
                        (Offer/ICE) /                  \ (Answer/ICE)
                                   v                    v
                       +--------------+             +--------------+
                       |   Peer A     | <=========> |    Peer B    |
                       |  (المتصل)    |  Direct P2P |  (المستلم)   |
                       +--------------+  Data/Media +--------------+
                                       (Audio/Video/Screen)
```

1. **مرحلة التنسيق (Signaling)**: يقوم خادم Node.js بدور المنسق فقط لتبادل بيانات الـ SDP (Offer / Answer) وعناوين الـ ICE Candidates بين الطرفين.
2. **مرحلة البث المباشر (P2P Streaming)**: بمجرد إتمام الاتصال، تتدفق بيانات الصوت والفيديو ومشاركة الشاشة مباشرة من جهاز لجهاز دون المرور على السيرفر، مما يحافظ على الخصوصية الكاملة وسرعة البث.

---

## ✨ المميزات الاحترافية (Key Features)

- 🚀 **اتصال مباشر P2P**: تدفق فوري للصوت والصورة بدون وسيط باستخدام بروتوكول WebRTC.
- 📱 **واجهة متجاوبة 100% (Responsive UI)**: تصميم أنيق يتكيف تلقائياً كشاشة متكاملة على الديسكتوب وتطبيق مرن للهواتف.
- 📊 **مؤشر جودة الاتصال اللحظي (Connection Quality & Ping)**: قياس البينج (RTT) وحالة استقرار الشبكة في الوقت الحقيقي وعرض شارة الجودة (ممتاز / جيد / ضعيف).
- 🎙️ **إدارة واختيار الأجهزة (Device Selector)**: إمكانية اختيار ميكروفون، كاميرا، وسماعة محددة وتغييرها بسهولة.
- 🖥️ **مشاركة الشاشة و PiP**: إمكانية مشاركة الشاشة أثناء المكالمة ودعم وضع الصورة داخل صورة (Picture-in-Picture) للمتصفح.
- 💬 **محادثة فورية مشفرة (In-Call Chat)**: تبادل الرسائل النصية المباشرة مع تنبيهات صوتية وشارة بالرسائل غير المقروءة.
- 🎉 **تفاعلات الإيموجي العائمة (Floating Emoji Reactions)**: إرسال تفاعلات حية تطفو على شاشة الطرفين مع مؤثر صوتي مميز.
- 🎵 **مؤثرات صوتية اصطناعية (Web Audio API)**: توليد نغمات الرنين والاتصال والاستقبال برمجياً دون الحاجة لأي ملفات صوتية خارجية.
- 🔔 **إشعارات المتصفح (Web Notifications)**: تنبيه بالمكالمات الواردة حتى لو كان التطبيق يعمل في الخلفية.

## 🚀 التثبيت والتشغيل السريع (Quickstart)

### 1. المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (إصدار 16 أو أحدث).

### 2. تثبيت الحزم
```bash
npm install
```

### 3. تشغيل الخادم
```bash
npm start
```
أو بالتشغيل المباشر:
```bash
node server.js
```

### 4. استخدام التطبيق
افتح المتصفح على:
```
http://localhost:3500
```

> **نصيحة للتجربة المحلية**: افتح نافذتين مختلفتين (مثلاً نافذة عادية ونافذة تصفح متخفي Incognito) على الرابط أعلاه، وانسخ كود أحدهما في خانة الاتصال بالأخرى لبدء مكالمة فورية واختبار كافة الميزات!
